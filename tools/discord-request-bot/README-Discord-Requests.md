# SpeshTV portable with Discord requests

Extract this entire ZIP and run **SpeshTV.exe**.

The request bot is bundled in **Discord-Request-Bot**. Follow **Discord-Request-Bot/README.md** to create the Discord bot, configure `.env`, register `/request`, `/queue`, and `/nowplaying`, and start it on this Windows PC.

In SpeshTV, open **Settings → Integrations → Discord announcements → Discord chat requests**, enable requests, and copy the connection token for the bot configuration.

Requesters choose a specific movie or series/season/episode, then confirm. Standby requests start playing; requests made while something is playing join the current queue. Finished announcements never ping roles. SpeshTV and the bot must both remain running. Start Discord screen sharing yourself.
