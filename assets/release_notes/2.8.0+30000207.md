# SpeshTV Windows 2.8.0+30000207

- The calendar updates TV, movie and library availability about every minute while it is open. Refreshes pause when the page is covered or the app is in the background.
- Refreshes retain your rows, filter, scroll position and focus. Returning from details restores the same row and reads the shared schedule again.
- Calendar labels use TV, Movies and Library, with Digital release, Physical release and In cinemas descriptions.
- Available means a matched library movie or episode; a series-only match is labeled Series available. Air times use Eastern EST/EDT; missing times remain Time unavailable.
- Calendar filters and Refresh have readable dark surfaces and blue focus borders. Studios now uses a distinct clapperboard icon.
- What’s New is bundled with this build and has a safe fallback if notes are unavailable.
- Full-color service artwork, translucent navigation, anime markers, episode context menus, native playback, authentication and media progress are retained.

- More Episodes always opens a season picker, including one-season shows. Back restores the selected season and picker position.
- Long seasons use a bounded virtualized grid with one scroll owner. Current/resume positioning happens once; artwork, badge and watch-state updates stay in place.
- Loaded episode data is reused by season, while episode actions retain their existing permissions and refresh behavior.
