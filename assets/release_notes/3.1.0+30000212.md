# SpeshTV Windows 3.1.0 candidate

- Who’s watching appears after signing in and on each cold launch when using Spesh Core viewing profiles.
- Create up to three profiles per account, with editable names and eight avatar colors. Profile 1 retains the account’s existing history.
- Switch profile from the account menu. Playback reports finish before the identity changes; secondary profile tokens remain session-only.
- Continue Watching, Next Up, favorites and watched state use the selected profile’s actual Jellyfin identity.
- Secondary profiles use online, server-backed playback; the owner’s offline history is not reused.
- Older servers show a compatibility option to continue with the original account.
- Centered Spotlight backdrops and fitted/clipped trailers, season artwork and Requests spacing are retained.

Requires compatible Spesh Core profile endpoints. Physical Windows/server integration testing remains pending.
- The already-signed-in original account can continue to its existing offline library when Core is unreachable; authentication refusals never enable this fallback.
